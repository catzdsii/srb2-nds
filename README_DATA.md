# SRB2 DSi Port - Data Files Instructions

To run Sonic Robo Blast 2 on DSi (via MelonDS or real hardware), you need the game data files.

## Required Files
You must have the following files in the `srb2` directory on your SD card (e.g., `sd:/srb2/`):

- `srb2.srb` (The main game data file)
- `zones.dta` (Levels)
- `player.dta` (Characters)
- `rings.dta` (Weapons/Items)
- `music.dta` (Music)
- `patch.dta` (Optional, patches)

## Installation
1. Create a folder named `srb2` on the root of your SD card.
2. Copy all the `.dta` files and `srb2.srb` into this folder.
3. Copy the `srb2_dsi.nds` executable to your SD card (can be in the root or `srb2` folder).

## Troubleshooting
- If you see a red "X" screen, it means the heap allocation failed. This is usually a memory limit issue.
- If the game hangs at "Loading main config...", please report the logs.
